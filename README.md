# git

Git 版本控制学习与练习仓库。

## 用途

本仓库用于记录 Git 的日常使用、常用命令与工作流笔记。

## 快速开始

```bash
git clone https://github.com/hanserlover/git.git
cd git
```

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `git status` | 查看工作区状态 |
| `git log --oneline --graph` | 查看提交历史 |
| `git add -A` | 暂存全部变更 |
| `git commit -m "msg"` | 提交 |
| `git push` | 推送到远端 |
